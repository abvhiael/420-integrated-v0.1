# High Country — nine approved cultivation backgrounds

Upload the nine PNG files to `apps/highcountry-web/public/assets/cultivation/environments/` in `abvhiael/420-integrated-v0.1`. Files are copied byte-for-byte from the approved uploads. Do not upload into `assets/highcountry/original-sixteen/`; these are browser scene backgrounds, not founder archive artwork.

The current build copies `apps/highcountry-web/public` to `dist` and would serve these under `/assets/cultivation/environments/`. This does not automatically wire scene selection; a future UI asset registry must do so.

See `manifest.json` for hashes, dimensions and exact canonical target paths.
