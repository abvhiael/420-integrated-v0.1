# Budtender — Consolidated artwork library

Phases 3.1 through 3.14, 368 canonical individual PNG files.

Images are in `assets/budtender/phase-3.x/`. Phase README and original manifest files appear in `documentation/`, and the eight 3.14 weather reference crops are preserved in `source_references/` (not counted among the 368 production assets).

Corrected production packs were used when available; exact bytes were checked against the per-phase SHA-256 inventory.

This ZIP is a local artifact, not evidence of a GitHub commit or gameplay registration.
