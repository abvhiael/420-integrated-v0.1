## Preservation and UI notes

No source artwork was redrawn, recolored, resized or sharpened. Only external warm-cream backgrounds were extracted to alpha. Textual contents of the artwork remain exactly as pictured; dynamic counts, inventory data and schedules must be app-rendered, not inferred from placeholder artwork.

Use `asset_manifest.json` for source hashes and dimensions. Check transparent silhouettes on both dark and light game backgrounds before deployment.
