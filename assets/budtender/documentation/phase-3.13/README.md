# Budtender · Phase 3.13 — Wall Décor Kit

32 individual transparent RGBA PNG assets from user-supplied crops, at original crop dimensions. No artwork redraw, resize, or style changes. Exterior light background was selectively cut away; interior cream-colored artwork is retained.

## Groups
- 8 framed artworks (`wall_art_*`)
- 8 architectural modules (`wall_panel_*`, `wall_trim_brass`, `wall_picture_rail`, `wall_corner_molding`)
- 8 botanical wall decorations (`wall_decor_planter_brass` through `wall_decor_living_wall`)
- 8 boutique upgrades (`wall_decor_mirror_brass` through `wall_decor_feature_premium`)

## Qualification boundary
Alpha transparency, naming and archive inventory can be automatically checked. Fine cutout quality and especially compatibility/seam matching of wall modules require visual/in-engine review; until that passes the phase should not be marked COMPLETE. See `asset_manifest.json`.
