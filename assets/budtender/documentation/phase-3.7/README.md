# Budtender — Phase 3.7 Plant & Botanical Kit

Status: PROCESSED — pending visual acceptance.

Contains all 32 production assets. This corrected edition replaces the initial pack, which retained cream backgrounds despite being described as transparent. All assets were cut from the exact user-supplied source crops, with no resizing or generative redraw. The RGB foreground artwork was preserved, with a new transparent alpha mask computed for the cream background.

**Caution:** Fine individual leaves, stems, and soft contact shadows should be checked at intended game scale before approval.

The included `asset_manifest.json` records dimensions, exact source filenames and hashes, alpha coverage, and output hashes.
