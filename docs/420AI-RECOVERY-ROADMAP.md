## Status language and two distinct destinations

- **Implemented** means source and/or tests are committed; not necessarily executed or passing.
- **Scoped CI-qualified** means a named workflow passed for a named immutable SHA and its recorded test scope. An older passing SHA does not qualify newer tests.
- **Integrated into `main`** means the recovery code has been reconciled with current `main`, checked on the actual combined commit, and merged. This is a **code integration milestone**, NOT paid-service release approval.
- **Testnet-qualified / released** additionally require an approved deployment, independently validated transaction/finality and balances, security and operating approvals. None of these may be inferred from local EVM tests or an unverified RPC flag.
