# 420Exchange PRE-01 — API/indexer interface reconciliation

**Audit date:** 2026-09-19. **Branch:** `feature/420exchange-v15.1-testnet-binding`, PR #352. **Basis:** inspected source files, not deployment or live responses. Companion: [PRE-01 inventory](420EXCHANGE-PRE-01-SOURCE-AND-TRUST-INVENTORY.md). **Status: PARTIAL** pending identification and validation of an Exchange-specific HTTP producer and route adapter; do not infer that none exists in other repositories.

## Located components and actual contracts

1. **420-indexer is a distinct package with source, tests and a build script:** [`420-indexer/package.json`](../420-indexer/package.json) runs TypeScript build/tests; it does **not** declare a `start` or `serve` script. [`420-indexer/src/chain-source.ts`](../420-indexer/src/chain-source.ts) defines an RPC-backed chain-source interface with blocks, receipts, logs, calls and code reads. [`420-indexer/src/event-canonicality.ts`](../420-indexer/src/event-canonicality.ts) defines observed/finalized/retracted/superseded event states. These are real indexer building blocks, but are not evidence of an operating process or Exchange read API.
2. **The general indexer public adapter is not the Exchange v13 read API.** [`420-indexer/src/api-surface.ts`](../420-indexer/src/api-surface.ts) implements `IndexerPublicApiAdapter420` for generic blocks, receipts, logs, transfers, protocol events, search and operational status. [`420-indexer/src/api-contract.ts`](../420-indexer/src/api-contract.ts) publishes *GET* `/health`, `/ready`, `/v1/status`, `/v1/blocks`, `/v1/transactions`, `/v1/protocols/events` and other `/v1` routes. The consumer list does not name 420Exchange. This is an API adapter/interface, not by itself proof of a running HTTP listener.
3. **Exchange browser requires another API shape.** [`exchange/web/core/exchange-client.js`](../exchange/web/core/exchange-client.js) calls `GET /v13/markets/{subjectId}/snapshot` and `GET /v13/history`; its snapshot needs `marketSubjectId`, `snapshotId`, positive `canonicalHead` and `canonicality`. Its history needs `records`, `recordId`, `subjectId`, `active`, `nextCursor`. Headers declare client schema `14.0`, while response validation requires Exchange API major `13`, minor <= 6. The indexer `/v1` route list does not provide these endpoints or DTOs; a separate Exchange API adapter/producer is required. **Do not point the browser `api.baseUrl` directly at the general indexer and assume schema compatibility.**
4. **Executable quote API is a different, currently unverified producer.** [`exchange/web/core/executable-quote-intake.js`](../exchange/web/core/executable-quote-intake.js) POSTs `420-exchange-swap-quote-request-v1` to explicitly configured same-origin HTTPS `.../executable-swap-quote`; its accepted response has `420-exchange-executable-swap-quote-v1`, quote ID, bounded timestamps, account/chain, canonical route, raw-unit input/minimum, and token projection inputs. It returns `REVIEW_CANDIDATE_ONLY` and does not authenticate source identity. The inspected generic indexer API defines only GET read routes, not this POST producer. It must not be manufactured from the snapshot response or a `verified:true` field.
5. **Runtime wiring unresolved.** [`exchange/web/runtime-config.json`](../exchange/web/runtime-config.json) has null network/RPC/API URLs and no executable quote URL. Neither `features.swap:true` nor a valid HTTPS URL proves qualified execution. Keep browser signing/sending disabled.

## Focused remaining PRE-01 checks (not testnet verification)

- **INV-01A:** Trace any separately located Exchange-specific HTTP API and quote producer, its actual server boot command/routes, deployment reader, access control and response construction. Search other application/service directories or linked repositories before marking absent.
- **INV-02A:** Trace the indexer process bootstrap and API transport binding (HTTP/SSE/WebSocket), persistence, checkpoint, ingest/reorg replay, schema and ownership. Test whether Exchange-specific projections already exist and compare them field-by-field to the browser validators.
- **INV-02B:** Define a source-of-truth and transport boundary: general indexer facts are read-only; Exchange market/route/swap quote construction needs its own qualified adapter. Never treat chain-indexed events, client fixtures or quote-producer assertions as proof of current available liquidity/allowance or executable routing.
- **INV-05:** Add offline contract tests to catch accidental `/v1`↔`/v13` route substitution and payload/version mismatches. No URL guesses or runtime-JSON-only execution enablement.

**Disposition:** This completes the **general indexer vs Exchange browser contract comparison**, not the entire PRE-01 phase. The next PRE-01 task is locating and inspecting Exchange-specific HTTP services and the actual indexer bootstrap, then closing or refining the remaining inventory entries with source-linked evidence. All real-send controls remain disabled; no live-gate status changes.
