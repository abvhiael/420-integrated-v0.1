## Required trust and domain boundary

`DISPLAY_SNAPSHOT` (possibly fixture-backed) -> `REVIEW_CANDIDATE_ONLY` (schema/freshness/session checked, origin **not authenticated**) -> future `TRUSTED_EXECUTION_QUOTE` (verifiable operator-approved identity, exact deployment/route/amount/recipient/fee/expiry/replay binding) -> future `REVIEWED_TRANSACTION` (same user-visible and canonical intent; fresh selected wallet/session and preflight) -> future `SUBMITTED_TRANSACTION` (hash is **not** success) -> separately confirmed/finalized/settled/reconciled state. No stage may be inferred from a caller-supplied `sourceAuthenticated`, `marketSource:'api'`, token `verified` flags, TLS, a configured endpoint or successful unit tests.

Canonical identities: chain ID, deployment manifest and code hashes; account/provider generation; token contract and sourced decimals (never symbol alone); market/route IDs and path commitment; integer raw-unit input, minimum **net** output, recipient, spender, fees, exact calldata/value and transaction fingerprint; observed/expiry times and replay identifiers. Invalid/stale/changed data clears review. Include explicit error and chain-vs-indexer conflict states. V14 fixture/catalog data cannot enter the V15 executable boundary.

## PRE-01 disposition / subsequent engineering tickets

- **INV-01 closed for PRE-01 mapping:** V13 Solidity reference policy != V13 HTTP implementation; general indexer transport != Exchange read/quote API. PRE-04 must define/build or locate and prove an executable-quote producer and its source authentication; PRE-10 must identify/build and contract-test Exchange market/history HTTP adapter. Do not assert universal absence of an external service.

- **INV-04 transferred:** eliminate competing V14/V15 execution identity and test DOM invalidation in PRE-02/03; V14 remains read-only.
- **INV-05 transferred:** automated cross-layer schema, import, fixture isolation and disabled-default checks in PRE-11.
