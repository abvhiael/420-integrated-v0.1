## Required trust and domain boundary

`DISPLAY_SNAPSHOT` (possibly fixtures) → `REVIEW_CANDIDATE_ONLY` (schema/freshness/session checked, origin unauthenticated) → future `TRUSTED_EXECUTION_QUOTE` (approved/verifiable producer, exact route/amount/recipient/fees/expiry/replay) → future `REVIEWED_TRANSACTION` (same visible/canonical intent, fresh wallet/session/preflight) → future `SUBMITTED_TRANSACTION` (a hash is not success) → separately confirmed/finalized/settled/reconciled state. HTTPS, schema, caller-supplied `sourceAuthenticated`, `verified` metadata, a configured endpoint, or unit tests cannot independently move a candidate across these boundaries.

Bind chain ID, deployment manifest and code hashes, account/provider generation, sourced token contract/decimals, market and route path, integer raw amounts and net minimum, recipient/spender, fees, calldata/value/transaction fingerprint, timestamps and replay identifiers. Changes to user input, account, chain, provider, runtime or navigation invalidate prior review. Distinguish API error, source trust, preflight failure, wallet rejection and chain/indexer disagreement. V14 fixture data must not enter V15 execution.

## PRE-01 disposition and subsequent engineering tickets

- **INV-01:** V13 Solidity policy is not a V13 HTTP implementation; general indexer is not the Exchange read/quote API. PRE-04 must locate/build and authenticate a quote producer; PRE-10 must locate/build a contract-tested Exchange read adapter. External services have not been exhaustively ruled out.
- **INV-02:** Generic indexer source and GET v1 HTTP factory were found, but an operator bootstrap combining RPC, SQL, ingest, API and listener and an Exchange-specific projection were not established. PRE-10/11 must verify or implement them.
- **INV-03:** ABI vectors, deployed code and adapter parity belong to PRE-04 and PRE-07–09 and subsequent live qualification.
- **INV-04:** PRE-02/03 must eliminate competing V14/V15 identity and test session/DOM invalidation; V14 remains display-only.
- **INV-05:** PRE-11 requires cross-layer schema/import/fixture-isolation/hard-off CI checks.
