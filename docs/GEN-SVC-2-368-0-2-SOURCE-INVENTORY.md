## Step 2 outcome and step 3 handoff

The boundaries above identify **two independent canonical file repositories and a separate derived discovery index**. A single authenticated, source-qualified publisher, validated atomic *paired generation*, and provenance/freshness-aware readiness are not yet wired. Step 3 must inventory every canonical write and visibility/lifecycle transition path, distinguish tests/adapters from deployed writers, and establish which paths may authorize publication. Do not add a new competing Location/Event lifecycle authority, equate a nonempty snapshot with real published data, or set Travel's public origin yet.
