# 420 AI

420 AI is the Genesis user application for requesting AI work against registered model versions and qualified off-chain providers while preserving explicit spend, privacy, deadline and verification constraints.

The application does not perform consensus inference and AI availability is not required for chain liveness. Canonical state records model/provider/job/escrow/reputation and result commitments; raw prompts, datasets, media and outputs remain off-chain unless intentionally published elsewhere.

Use [Getting started](getting-started.md) for a safe first job and [Developer integration](developer/index.md) for request/model/provider boundaries.
