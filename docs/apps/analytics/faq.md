# Analytics FAQ

**Are Analytics numbers canonical?** No. They are reproducible derived views over canonical/public source data.

**Why can today's number change?** The active source window may still include pre-finality data or incomplete indexing.

**Can Analytics decide governance outcomes or validator eligibility?** No. It can report those canonical states but does not own them.

**Can I reproduce a metric?** Published metrics should document enough source/window/formula information to make independent reproduction possible.

**Do I need a wallet connection?** Not for ordinary public dashboards.
