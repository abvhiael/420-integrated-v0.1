# Getting started with 420 Analytics

1. Open the qualified Analytics destination.
2. Confirm network, data freshness and the displayed source window.
3. Select a dashboard or metric family.
4. Check whether the metric uses head, safe or finalized data.
5. Inspect the metric definition, time range and provenance before comparing values.
6. Follow links to Explorer or the owning protocol when a specific canonical fact matters.

Analytics is read-only in the Genesis profile. Viewing a dashboard should not require a transaction signature or reusable Wallet capability.
