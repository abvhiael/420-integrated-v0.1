# 420 Arbitration concepts

A **domain policy** defines resolver identities, evidence/appeal windows and appeal cap. A **case snapshot** freezes those terms at open time.

An **evidence commitment** is a hash of evidence, not the evidence payload itself. A **ruling commitment** records the selected resolver's decision/reasoning. A **remedy commitment** describes the remedy but does not execute it.

Arbitration finality and chain finality are separate.
