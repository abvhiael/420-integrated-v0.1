# 420 Arbitration

420 Arbitration is the user-facing application for protocol disputes, evidence commitments, rulings, bounded appeals and arbitration finality.

It coordinates a registered dispute process without becoming a universal legal authority, asset custodian or cross-protocol superuser. A finalized ruling can be authoritative for its registered case while still requiring the originating protocol's own explicit remedy-consumption path.

Use [Getting started](getting-started.md) for the case lifecycle and [Developer integration](developer/index.md) for bounded ruling consumption.
