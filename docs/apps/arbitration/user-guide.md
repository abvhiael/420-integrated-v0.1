# 420 Arbitration user guide

Users can inspect case parties, domain/origin, current round, evidence deadline, selected resolver, evidence commitments, ruling, appeal window and finalization state.

Only the parties may submit evidence or appeal. Each round accepts at most one ruling from the selected resolver. Appeals are bounded by the case's snapshotted policy and current implementation cap of three.

A case may finalize only after the current ruling's appeal window closes.
