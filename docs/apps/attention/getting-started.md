# Getting started with 420 Attention

Participation is opt-in. Review the campaign, consent policy, verifier, reward rate, per-account cap, campaign window and privacy expectations before enabling consent.

A valid proof requires current consent, an active campaign, the campaign's bound verifier, an observation timestamp inside the campaign window and a single-use nullifier. Reward entitlement is created only after proof validation and fund reservation.

Do not provide wallet keys, private browsing histories or unrelated personal data to sponsors or verifiers.
