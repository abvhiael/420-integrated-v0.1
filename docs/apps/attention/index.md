# 420 Attention

420 Attention is the user-facing application for opt-in sponsor-funded engagement campaigns denominated in native `$420`.

The protocol makes consent, campaign economics, proof commitments, reward entitlements and sponsor liabilities canonical while keeping campaign media, raw behavioral telemetry, device identifiers and private audience data off-chain.

Use [Getting started](getting-started.md) for consent/campaign/reward basics and [Developer integration](developer/index.md) for proof and reward integration.
