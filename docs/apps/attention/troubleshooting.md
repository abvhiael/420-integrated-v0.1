# 420 Attention troubleshooting

If a proof is rejected, check current consent, campaign activity/window, verifier identity, nullifier reuse and proof/evidence fields. If a reward cannot reserve, check campaign funding and per-account cap.

If a reward is reserved but cannot be claimed, verify recipient identity and canonical reward state. If a campaign closes, unused sponsor funds cannot refund until reserved rewards clear.

When dashboards or notifications disagree with chain state, prefer canonical Attention consent/campaign/proof/reward/Treasury state.
