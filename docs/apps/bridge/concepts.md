# 420 Bridge concepts

**Chain identity** binds route chain ID to an explicit network fingerprint and verifier/chain family.

**Bridge asset** maps an external asset to its canonical local representation under bridge policy.

**Route** binds asset, source/destination chains and assets, adapter, verifier configuration and direction.

**Proof adapter** verifies external evidence but does not override local policy/risk/replay checks.

**Transfer identity** is replay-protected and domain-bound to the route, asset, sender/recipient, amount and source references.
