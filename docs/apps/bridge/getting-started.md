# Getting started with 420 Bridge

Verify the source network fingerprint, destination network, asset representation, bridge route, direction, recipient and amount before signing.

Do not rely on ticker symbols or familiar external chain numbers alone. Bridge identity is bound to explicit chain/network fingerprints, asset IDs, route IDs, adapter/verifier configuration and canonical local representations.

Expect cross-chain completion to take longer than local transaction inclusion because source finality/proof requirements must be satisfied.
