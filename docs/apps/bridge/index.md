# 420 Bridge

420 Bridge is the user-facing application for verified, replay-protected cross-chain value movement through approved chains, assets, routes, adapters and risk controls.

A valid external proof alone is never enough to release value. Current route direction, canonical asset identity, verifier configuration, risk limits, replay protection and local safety state must all agree.

Use [Getting started](getting-started.md) before moving external assets and [Developer integration](developer/index.md) for route/proof semantics.
