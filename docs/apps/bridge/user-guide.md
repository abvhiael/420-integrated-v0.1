# 420 Bridge user guide

Select a supported route and direction, verify the canonical source/destination asset identities, enter the recipient/amount and review fees/limits before authorizing the transfer.

Track the canonical transfer lifecycle rather than assuming submission means completion. States may include source pending/finalized, proof pending, verified, destination pending, completed, retryable failure, paused, disputed, expired or refunded.

If a route is suspended or risk limits are exhausted, wait for safe recovery instead of attempting an unverified bypass.
