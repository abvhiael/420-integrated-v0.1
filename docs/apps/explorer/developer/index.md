# 420 Explorer developer integration

Integrate Explorer as a read-only consumer surface. Use the stable 420Indexer `/v1` API and preserve provenance/finality metadata in every downstream view.

Do not scrape Explorer HTML as a canonical API and do not use Explorer labels as authorization input. For machine integration use the Indexer/API contracts and Registry-backed service discovery.
