# Explorer FAQ

**Is Explorer the blockchain?** No. It renders indexed projections of canonical chain/protocol state.

**Can Explorer reverse a transaction?** No.

**Does an Explorer label prove an address is official?** No. Verify Registry and canonical deployment context.

**Why can a recent transaction change status?** Pre-finality history can reorganize or an indexer can catch up.

**Do I need to connect my wallet?** Not for normal public inspection.

**Can I build another Explorer?** Yes. Explorer is replaceable infrastructure and the shared read API is designed for independent consumers.
