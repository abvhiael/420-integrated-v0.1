# Explorer fees

420 Explorer does not charge a protocol fee for reading public indexed data in the Genesis profile.

Viewing blocks, transactions, addresses, contracts and other public projections does not itself create an on-chain transaction or gas charge. Third-party hosting, API plans or future optional services may have separate commercial terms, but those are not canonical network fees.

Following Explorer into a state-changing dApp action can create normal gas or protocol-specific costs; review those costs in the destination application and Wallet before signing.
