# Getting started with 420 Explorer

Use Explorer to inspect public chain activity without signing or granting wallet authority.

1. Open the qualified Explorer destination from 420 Wallet, 420 Registry-backed discovery or another canonical release channel.
2. Confirm the displayed 420 Integrated network.
3. Search by block number/hash, transaction hash, address, contract or supported registered object.
4. Check the displayed head/safe/finalized status before treating recent data as settled.
5. Follow provenance links back to transactions, logs, Registry records or canonical protocol objects when a fact matters.

Explorer is read-only. A normal inspection flow should not request a transaction signature, reusable capability or spending permission.
