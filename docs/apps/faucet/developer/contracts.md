# Contracts

420 Faucet should not be treated as a canonical monetary-policy contract. Its frozen Genesis classification is `TESTNET_ONLY`, and the application decision explicitly states that Faucet never participates in mainnet genesis economics.

The active service is backed operationally by a dedicated testnet Faucet allocation or operator-funded test account. The canonical proof of distribution is the resulting execution-chain transfer, not a Faucet-specific contract state machine.

Generated deployment/reference details, if any, belong in DOC-10 rather than being invented here.
