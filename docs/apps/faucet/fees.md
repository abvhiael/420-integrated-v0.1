# Fees and limits

420 Faucet does not charge a protocol fee for a normal testnet request.

Current distribution policy:

| Limit | Value |
| --- | ---: |
| amount per successful request | 42 testnet `$420` |
| per-address cooldown | 24 hours |
| per-IP request limit | 5/hour |
| daily operator distribution cap | 42,000 testnet `$420` |

These are operational testnet controls, not native `$420` monetary policy. They may be revised for future testnet operations without implying any corresponding mainnet rule.

Testnet `$420` has no monetary value.
