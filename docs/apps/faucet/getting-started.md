# Getting started

1. Confirm the selected network is an official 420 **testnet**, not mainnet.
2. Use a test account address you control. Never submit a private key, seed phrase or signing secret.
3. Open the discovered Faucet endpoint from Wallet or Developer Hub.
4. Complete the required CAPTCHA or equivalent abuse-control challenge.
5. Submit the address once.
6. Wait for the service response, then verify the resulting balance through the testnet RPC/Wallet/Explorer rather than treating the Faucet response as canonical balance proof.

A successful request normally distributes **42 testnet `$420`**. The same address is subject to a **24-hour cooldown** and source IPs are limited to **5 requests per hour**.

Testnet `$420` has no monetary value, no redemption promise and no mainnet entitlement.
