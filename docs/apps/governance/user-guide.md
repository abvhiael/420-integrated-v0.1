# 420 Governance user guide

Users can inspect proposal class, voting window, snapshot source/revision, quorum/approval thresholds, required houses, committed action hash, current tallies, queue status, timelock and execution state.

Ballots are `FOR`, `AGAINST` or `ABSTAIN`. Participation including abstentions contributes to quorum; approval is based on decisive FOR versus AGAINST votes. Dual-house proposals require both required houses to pass.
