# 420 Identity concepts

A **profile** is a protocol identity controlled by an account, not automatically a real-world identity. **Metadata hash** commits to profile metadata without requiring all content on-chain.

A **credential** records issuer, subject profile, type, claim hash, issue time, optional expiry, revocation and subject rejection.

An **issuer trust class** is bounded ecosystem policy. It is not a reputation score.

A strong Names↔Identity link requires bilateral agreement from both protocols.
