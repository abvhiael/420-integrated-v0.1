# Getting started with 420 Identity

You may create/use a pseudonymous profile when an application benefits from stable public identity or credentials. Keep private personal data off-chain unless the application explicitly requires a public commitment.

A profile has a controller, metadata commitment, optional primary `.420` name, timestamps and active state. Credentials are issued by governed issuers and can expire, be revoked or be rejected by the subject.

Before trusting a credential, check current validity and issuer status rather than relying on a cached badge.
