# 420 Launchpad concepts

- **Project** — a registered launch subject with a controller, sale asset, metadata commitment and issuance commitment.
- **Sale** — the bounded sale configuration associated with a project.
- **Allocation** — protocol-recorded entitlement or allocation state for a participant.
- **Controller** — the address authorized for project-scoped actions allowed by policy; it is not universal protocol authority.
- **Metadata commitment** — a hash commitment to project information; it does not make the information truthful.
- **Issuance commitment** — a commitment to the intended asset/issuance configuration; users must still verify the resulting asset and transaction.
