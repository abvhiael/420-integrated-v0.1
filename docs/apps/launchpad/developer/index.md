# 420 Launchpad developer integration

Integrations should discover canonical addresses through the designated Registry/release configuration and treat contract state as authoritative.

Use the project registry for project identity, sale registry for sale configuration, allocation registry for participant allocation state, and router only for the bounded actions it exposes. Do not infer project endorsement from registration.
