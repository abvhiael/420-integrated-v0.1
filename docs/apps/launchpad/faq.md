# 420 Launchpad FAQ

**Does a Launchpad listing mean 420 Integrated endorses a project?** No. Registration provides protocol identity and state, not investment endorsement.

**Can a project controller move funds from my Wallet?** Not without the Wallet authorization required by the actual transaction/capability path.

**Is project metadata canonical?** The commitment can be canonical; off-chain descriptive content is not automatically truthful or authoritative.

**Can support reverse a finalized contribution?** Only remedies explicitly supported by the relevant contracts/policy can change state. Support documentation cannot create reversal authority.
