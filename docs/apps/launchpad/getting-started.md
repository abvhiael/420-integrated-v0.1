# Getting started with 420 Launchpad

Before participating, confirm the selected network, Wallet account, project identifier, controller address, sale asset and active sale parameters from canonical chain state. A catalogue or Launchpad page is presentation; the signed transaction and contract state are authoritative.

Typical flow:

1. open the project record;
2. verify controller, metadata commitment and issuance commitment;
3. review the active sale configuration and allocation rules;
4. connect 420 Wallet and inspect the exact spend/approval request;
5. submit only if the transaction matches your intent;
6. wait for canonical receipt/finality before treating participation as complete.

Never disclose recovery material or signing secrets to a project, operator or support channel.
