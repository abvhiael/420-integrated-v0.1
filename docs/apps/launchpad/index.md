# 420 Launchpad

420 Launchpad is the governed project-launch and allocation surface for qualified ecosystem projects. It records project identity, sale configuration and allocation state through the Launchpad contract family while relying on canonical Registry, Token, Wallet and Governance authority.

Launchpad does not make a project safe, legitimate, profitable or endorsed merely because it is registered. Users must verify the project controller, sale asset, policy state, terms and transaction details before authorizing funds.
