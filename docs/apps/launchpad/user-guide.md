# 420 Launchpad user guide

## Browse a project

Use the project identifier to inspect the canonical project record. Metadata may be off-chain; compare its commitment with the value stored by the protocol.

## Participate in a sale

A sale must be active and bound to the expected project and sale asset. Review contribution amount, limits, deadlines and any eligibility or allocation conditions before signing.

## Check allocation

Allocation state is separate from a marketing promise. Treat the Launchpad allocation registry and resulting transaction receipts as the authoritative protocol evidence.

## Exit or recovery

Do not assume cancellation, refund or reversal exists unless the exact sale configuration and contracts provide it. A failed or timed-out client request does not prove the transaction failed; verify canonical transaction state before retrying.
