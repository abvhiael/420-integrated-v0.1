# Getting started with 420 Names

Before registering a `.420` name, confirm the correct network and understand that names are leased and expire. Registration uses commit/reveal rather than a single public transaction.

Current rules enforce a minimum commitment age of 60 seconds, a maximum commitment age of 24 hours, registration periods from 30 to 365 days, and labels up to 63 protocol input bytes/characters.

Before sending value or relying on a name, re-resolve it and confirm the record is unexpired.
