# 420 Names user guide

Users can commit to a desired label, reveal/register it after the minimum delay, renew it before expiry, update forward resolution, set optional profile/service references, nominate a new owner, and accept transfers.

Transfers are intentionally two-step. When the pending owner accepts, resolution resets to the new owner's address and prior Identity/service links are cleared. Old associations must be re-established explicitly.

Reverse names are valid only while the requesting address remains the current forward-resolution target.
