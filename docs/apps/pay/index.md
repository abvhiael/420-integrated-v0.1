# 420 Pay

420 Pay is an approved Genesis protocol and user application. Its canonical service ID is `420/service/pay/v1`. Product scope includes consumer payments, merchant invoices, checkout and POS. The proposed website is `https://pay.420integrated.org`. Consumer and merchant web, PWA, POS, hosted checkout, Android, iOS and developer integrations remain planned. [Wallet discovery](../../users/wallet/dapp-connections.md#420-pay-in-wallet) and [AppStore discovery](../appstore/user-guide.md#find-420-pay) describe the approved scope. The [Pay roadmap](PAY-APP-ROADMAP.md) and [deployment qualification](deployment-operations.md) track availability.

420Wallet authorizes transactions. The Pay contracts own invoice, payment, settlement and refund state. ProtocolRegistry resolves the active deployment and its code identity. Explorer and Indexer display evidence from that state.
