# 420 Pay

420 Pay is an approved Genesis protocol and user application. Its canonical service ID is `420/service/pay/v1`. Product scope includes consumer payments, merchant invoices, checkout and POS. Live service availability and application deployment remain subject to the [Pay roadmap](PAY-APP-ROADMAP.md) and [deployment qualification](deployment-operations.md).

420Wallet authorizes transactions. The Pay contracts own invoice, payment, settlement and refund state. ProtocolRegistry resolves the active deployment and its code identity. Explorer and Indexer display evidence from that state.
