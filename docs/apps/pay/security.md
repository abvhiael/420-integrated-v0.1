# Security and privacy

Check the chain, active Registry deployment, implementation code identity, and qualified application origin before signing. Verify the merchant and invoice from canonical evidence. Treat QR codes and links as inputs that require review.

Keep merchant line items, customer references and location metadata within authorized private storage. Pay receipts and status views derive from canonical events. Reorganizations can invalidate a projection. Wallet owns signing authority and Pay contracts own settlement and refund authorization.

See [deployment gates](deployment-operations.md) and [permissions](permissions.md).
