# 420 Registry troubleshooting

If a service appears missing, first verify the selected network and exact service ID. If a cached client shows an older version, refresh canonical Registry state.

If the current version is inactive/deprecated, do not bypass the condition with an arbitrary address. If Explorer/Search disagrees with Registry, treat those as stale projections and prefer canonical chain state.

For failed publication transactions, inspect the transaction receipt, authorization failure, version sequencing and implementation/code-hash validation.
