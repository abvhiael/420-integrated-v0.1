# Search integration examples

## Exact address lookup
Normalize the address, query the address domain, require chain/provenance metadata, then display optional Names/Identity enrichment separately.

## Service discovery
Search for a service name, then require Registry-backed service/version provenance before constructing a trusted destination.

## Free-text asset discovery
Display relevance-ranked candidates, clearly label sponsored placement, retain canonical asset identifiers, and require the user/integrator to select and verify the intended asset before any state-changing action.
