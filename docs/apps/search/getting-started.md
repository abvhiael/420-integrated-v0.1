# Getting started with 420 Search

1. Open the qualified Search destination.
2. Confirm the displayed network and indexed/finalized status.
3. Search by address, transaction, block, `.420` name, registered service, public Identity profile, asset or supported public object.
4. Inspect the result's type and provenance before acting on it.
5. Follow canonical links to Explorer, Registry or the responsible protocol application when verification or action is required.

Search is for discovery. A result appearing high in the ranking is not proof that it is official, safe, endorsed or current.
