# 420 Search

420 Search is the ecosystem-wide public discovery application for 420 Integrated. It unifies search across explicitly indexable chain activity and registered public protocol data, including blocks, transactions, addresses, contracts, services, Names, public Identity profiles, assets, validators, public listings and other public domains.

420 Search is **derived/rebuildable presentation**, not protocol authority. Ranking, snippets, categories, caches and recommendations are replaceable. Canonical truth remains with the chain, Registry and the protocol that owns each record.

Start with [Getting started](getting-started.md) or [Developer integration](developer/index.md).
