# Search security and privacy

- Never treat rank as trust.
- Verify official services through Registry-backed provenance.
- Keep raw addresses/hashes visible beside labels.
- Treat stale/wrong-network results as degraded.
- Sponsored results must never impersonate canonical registration.
- Never enter private keys, recovery material or passkey secrets into Search.

Search excludes private Messenger content, protected Commons content, encrypted Resource payloads, private Identity fields and raw Attention telemetry. Public commitments do not authorize recovery or indexing of protected content.
