# Search troubleshooting

## Expected result is missing
Check spelling/identifier, network and indexed height. The source may be public but not yet indexed, or outside the supported public domain taxonomy.

## Result points to stale data
Inspect provenance and finalized/indexed status, then verify through Explorer/Registry or the owning protocol.

## Wrong entity with same name
Names and free-text labels can collide. Use canonical address/object identifiers and Registry/Identity provenance.

## Sponsored result confusion
Sponsored placement should be labeled. If it is not, do not infer endorsement; verify independently.

Share only public identifiers, query text, app version and non-sensitive diagnostics with support.
