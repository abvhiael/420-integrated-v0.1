# 420 Search user guide

Search results are grouped by domain so users can distinguish addresses, transactions, contracts, registered services, names, identities, assets, validators and other public objects.

## Resolver-style searches
For exact identifiers such as hashes, addresses and registered names, prefer exact resolution over relevance ranking.

## Discovery searches
Keyword/category queries may return ranked results. Relevance is a presentation decision and must not alter canonical fields.

## Sponsored results
Any sponsored placement must be conspicuously labeled. Sponsorship cannot create official registration, ownership, rights, identity, trust or payment status.

## Provenance
Before acting, inspect chain ID, block/log/transaction provenance or Registry/protocol source links. Search should expose enough context to detect stale data and wrong-network results.
