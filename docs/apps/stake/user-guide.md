# 420 Stake user guide

Use 420 Stake to inspect validator registration, bond composition, activation progress, active/inactive lifecycle state, voluntary-exit timing, cooldown/withdrawal timing and accrued rewards.

Genesis constants include a 17,640-block activation delay, one-rotation voluntary-exit notice, three-rotation normal cooldown and 105,840-block withdrawal delay.

There is no public delegation at Genesis, and larger collateral does not create public-governance weight.
