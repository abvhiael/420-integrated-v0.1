# 420 Status

420 Status is the public network and service-health presentation layer for 420 Integrated. It aggregates health, readiness, freshness, maintenance and incident information without becoming authority for finality, balances, settlement, validator eligibility or protocol state.

A green component is not proof of canonical success; a red component is not by itself proof of consensus failure.
