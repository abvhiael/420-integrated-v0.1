# 420 Swap concepts

**Quote**: a time-bounded expected execution result, not a guarantee.

**Route**: the approved execution path/adapters used for a trade.

**Minimum output**: the user's fail-closed floor for delivered assets.

**Slippage/deviation**: bounded execution-price movement relative to the user's quote/guard policy.

**Scoped authorization**: permission limited by asset/market/action and amount rather than ambient spending power.
