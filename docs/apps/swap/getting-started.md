# Getting started with 420 Swap

Verify network identity, the input/output assets, route, amount, minimum received and all quoted fees before signing.

A quote is informational until executed. Prices may move, routes may become unavailable and pre-finality state may reorganize. If a quote expires or safety checks fail, obtain a new quote instead of widening limits blindly.

Wallet approval must be scoped to the intended asset/amount/action wherever possible.
