# 420 Swap user guide

Choose the asset pair and exact input amount, inspect the quoted route and expected output, review price impact/deviation and fees, set an acceptable minimum output, then approve the bounded Wallet action.

Execution may use one or more approved venues/adapters beneath the canonical routing boundary. Successful submission is not the same as finalized settlement; confirm canonical transaction status afterward.

Do not retry a failed trade with looser limits unless you deliberately accept the changed risk.
