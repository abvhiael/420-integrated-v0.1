# 420 Token FAQ

## Does 420 Token create native `$420`?
No. Native `$420` is the chain currency.

## What is the creation fee?
Exactly 42 native `$420`, plus gas.

## Does an approved template mean the token is audited or endorsed?
No. Template qualification only defines the approved factory profile.

## Will my token automatically appear in Swap or Bridge?
No. Those protocols have separate qualification rules.
