# Getting started with 420 Token

Choose the template that matches the intended supply/ownership/mint/burn/permit/vote/NFT behavior. Review the configuration carefully because deployed token behavior comes from the selected template and its parameters.

TokenFactory charges an exact creation fee of **42 native `$420`**, in addition to ordinary network gas. The creation fee is forwarded atomically to the configured community treasury; if forwarding fails, deployment reverts.

Verify the resulting deployment address and provenance after finalization.
