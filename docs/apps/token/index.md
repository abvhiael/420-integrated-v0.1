# 420 Token

420 Token is the user-facing application for self-service deployment of qualified ERC20, ERC721 and ERC1155 assets from governed templates.

420 Token does **not** issue native `$420`. Native `$420` is the chain currency used for gas and the exact TokenFactory creation fee.

Deploying a token records deterministic provenance, but does not automatically make that token listed, bridged, audited, verified, endorsed or safe.
