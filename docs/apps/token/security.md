# 420 Token security

Choose the template carefully: mintability, caps, burnability, permits, vote checkpoints and NFT ownership semantics materially affect risk.

Verify the factory/Registry identity, chain ID, selected template/version, ownership recipient and configuration before signing. Treat symbols/names as presentation only; the deployed address is the canonical asset identity on-chain.

Do not interpret template approval as an audit, endorsement or guaranteed market/bridge eligibility.
