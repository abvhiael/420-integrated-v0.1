# 420 Token user guide

Select a currently enabled template, enter the required metadata/configuration, review ownership and supply semantics, then approve the factory deployment in Wallet.

After deployment, record the token address, template/version and configuration provenance. Existing deployments are not rewritten if governance later disables a template for future use.

Any later listing in Swap/Exchange, use in Pay, or bridge qualification requires those protocols' separate eligibility rules.
