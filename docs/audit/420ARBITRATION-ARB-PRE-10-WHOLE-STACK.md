## Core gate and artifact identity

- The local Genesis workflow twice deploys the *real* canonical GovernanceTimelock, PolicyRegistry, CaseRegistry, RulingRegistry and Router, enforces the one-time reciprocal binding, registers/publishes/recovers the ProtocolRegistry service and retains exact runtime bytecode/receipt commitments. The expanded verifier refuses a manifest missing A/B/C/D/E/F/H coverage, or diverging across the independent runs.
- The browser qualification builds actual Foundry artifact ABI and runs the application in Chromium against a local Anvil RPC. A locally injected EIP-1193 test provider gives accounts to the browser while on-chain transactions are actually mined and reconciled; neither it nor a mock response can grant governance or remedy custody.
- The Indexer qualification compiles its TypeScript, uses PostgreSQL service state rather than in-memory stand-in, runs canonical reorg/API recovery suites, then verifies real compiled Foundry event ABI against the versioned descriptor.
- Consumer tests run actual local Foundry contracts with unchanged property/negative assertions, alongside locked Commerce service test dependencies.
