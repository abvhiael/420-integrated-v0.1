Reproduce creation/runtime bytecode, actual constructors, storage, ABI, Registry bindings, Timelock, sponsorship and compensation wiring, capability grants, retire/sweep restrictions and recovery. 3. **Local transfers can fund actual locally deployed and registered Vaults** and verify solvency/permissions/settlement via Vault/Registry/Treasury/Stake integration tests. No claim is made that those funds have moved on testnet.
4. **Local Wallet, Registry, Indexer, Stake, Treasury, Explorer and Governance end-to-end tests**, negative tests, byte/manifest/protocol drift checks and cold-start/recovery runbooks remain pre-testnet engineering.
5. **Founder address collection and genuine EIP-191/EIP-1271 pre-Genesis proofs, canonical V4 source commitment preparation, independent authorization/signoff and candidate freeze** are pre-testnet external *authorization inputs* — **not technically blocked by an active testnet**.
