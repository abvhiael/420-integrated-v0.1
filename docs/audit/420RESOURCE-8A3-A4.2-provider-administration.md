# A4.2 — Provider administration authority

The existing UPDATE_PROVIDER capability is restricted to metadata changes: delegated callers must supply the unchanged stored stake reference. The operator retains the existing combined update selector and authority to change the reference when inactive. Collateral eligibility continues to be established independently by the bound collateral authority, not the supplied reference. The existing SET_PROVIDER_STATE capability permits ordinary activation and suspension subject to eligibility, but irreversible retirement is operator-only. Sponsorship remains operator-only and cannot be changed after retirement or permanent disqualification. Governance-only disciplinary reinstatement, suspension, disqualification, admission and policy operations are unchanged. Custody remains with the actual collateral owner; permissionless execution of an already authorized penalty does not confer penalty authorization.

No new capability IDs, ABI selectors or storage slots are introduced. Existing metadata delegates must read and preserve the current stake reference; state delegates must return retirement requests to the operator. No grant migration is required. Qualification exercises the real capability registry, cross-operation denial, revoked grants, positive operator/delegate paths and disciplinary enforcement. CI qualification is pending.
