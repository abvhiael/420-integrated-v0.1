## Native reward issuance and exact settlement

- The native `420/SYSCALL/REWARD/V1` EVM call is authenticated by existing consensus batch/root, execution block, parent hash and sequence. It **never** exposes a public native mint, privileged EOA mint key, ordinary transaction, contract-side mint or discretionary Treasury funding operation.

It computes **realized earned gross** only: proposer + actual certified selected participants + Attention + Development; no unearned committee pool or unselected rewards are issued.
- The patched Geth `Process420SystemCalls` path runs both for imported-block execution and payload building. It credits exactly the verified realized amount via native `StateDB.AddBalance` to **0x0420** before the pre-existing **zero-value** consensus EVM call. The source snapshot of any forced pre-existing native balance is preserved; a malicious SELFDESTRUCT to the reward contract cannot indefinitely halt consensus or become an approved reward. A wrong amount, overflow, payout error or non-matching pre/post balance invalidates the block.
- `RewardController` V3 immediately distributes native assets: unsponsored proposers and participants get their earned gross amounts; **fully sponsored-origin** validators with remaining protocol principal get **90% net** while the remaining **10% is paid natively to 0x0426 CommunityRewardReserve** in the same state transition. Attention 0x0421 and Development 0x0422 receive their actual consensus-selected amounts. The system emits individual `NativeRewardPaid` events and independent `SponsoredValidatorRewardAllocated`, `CommunityRewardBackingReceived`, `CommunityRewardSettled` and `RewardApplied` commitments. The legacy separate `fundCommunityRewardBacking` and `settleCommunityRewards` methods are deliberately disabled to prevent post hoc transfers, double counting, or unbacked rewards.
- The live Geth state transition is still **not** a stand-alone Ethereum transaction: source evidence is the pinned native system-call batch and canonical execution block/log archive. No invented normal transaction hash or mainnet settlement receipt is used.
