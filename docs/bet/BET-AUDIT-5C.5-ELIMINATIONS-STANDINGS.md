# 5C.5 — Elimination, standings and final-table handling

## Approved rules

The user approved these rules for this step:

1. A player eliminated in the same hand finishes ahead of another eliminated player if their stack **at hand start, before blinds**, was larger. Equal starting stacks tie. Tied players share the affected finishing-place band; prize splitting is the later payout executor's responsibility.
2. Every multi-table round initially uses a synchronized barrier. Each active table must finish its one planned canonical hand before standings or the next round advance. Transaction order cannot choose finishing places.
3. Cross-table eliminations tie by **corresponding local finish tier**. Distinct starting-stack groups within each table form local tiers, largest first. Tier zero across tables ties, then tier one, and so on. This explicitly resolves the otherwise contradictory case where two differently sized stacks bust at one table and one player busts elsewhere. This is the platform's approved versioned rule, not a claim that all external tournament operators use it.
4. Retain the qualified 5C.4 deterministic highest-table closure and verifiable reseating policy. No optional final-table redraw. Heads-up uses the button as small blind and preserves the established big-blind transition rule.
5. The approved finite re-entry/rebuy limits, identical price/fee/starting stack, hard elapsed-time/earlier-level cutoffs, zero-stack rebuy timer, one active verified identity, one final finish per person and automatic sole-survivor closure remain authoritative.
