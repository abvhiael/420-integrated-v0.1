# C02.6 — Optional 420AI-assisted extraction and comparison

Canonical roadmap: optional 420AI-assisted extraction and comparison with cited spans; label every output as a proposal, validate it and prevent tool access or policy activation from document instructions.

The Go interface `AITextProposer` permits only plain-text submission and a structured proposal result. It intentionally exposes **no** tool invocations, policy mutation hooks, reviewer credentials or publication interfaces. The validation boundary `AIProposalValidator.Extract` requires a bounded input, exact source and immutable snapshot digest, explicit `UNTRUSTED_AI_PROPOSAL` label, nonempty comparison, and one or more verbatim cited spans present in the original text. Invalid citations, invented source/snapshot, promotion to approved status, absent providers, and oversized requests fail closed. All accepted outputs remain `ReviewRequired: true` and `Authorized: false`.

This is an optional interface suitable for later independently sandboxed 420AI integration. The repository step **does not** establish a live 420AI provider, secure outsourced processing agreement, independent model evaluations, human legal review or policy activation. C02.7 owns the review intake queue. C02.10 owns Level 2; C08.5 owns Level 3. The deployed model endpoint, workload isolation and acceptance belong in C09.5 when appropriate.
