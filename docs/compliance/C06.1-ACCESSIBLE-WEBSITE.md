# C06.1 — Accessible design system and responsive website

Canonical requirement: **Accessible design system and responsive website; proposed domain `compliance.420integrated.org`, subject to existing hosting/domain decisions.**

Static app at `compliance/web/index.html` with scoped tokens and responsive CSS in `compliance/web/styles.css`. It provides semantic landmarks, a keyboard skip link, visible high-contrast focus, single H1 and clear section hierarchy, narrow-screen stacked cards, viewport sizing, reduced-motion and forced-colors support, accessible labelled navigation, no external runtime dependencies, and a development disclosure that **no live jurisdiction coverage, legal certification, authenticated evaluation, or private reviewer actions are available**. Public cards explicitly read *Not published*. This is a website foundation, not implementation of C06.2–C06.7.

**Domain:** `compliance.420integrated.org` is a proposal only. No DNS, Cloudflare Pages project, Route, environment secrets, or live deployment is authorized by this step; defer hostname reservation, Pages root `compliance/web`, production branch, deployment artifact and CORS/TLS verification to C09/C10 after hosting decision. Do not impersonate an active Compliance provider.

**Level 1:** `scripts/verify-compliance-c06-1.py` statically guards landmarks, lang, skip target, viewport, navigable anchors, reduced motion, forced-colors, responsive grid, public safety disclaimers and absence of injected scripts. App-specific CI executes it alongside retained Compliance regressions. Full browser screen reader, automated axe, multi-breakpoint screenshot checks, sessions and interactive private flows are specifically required at **C06.8** and milestone **C06.9** and remain unverified here. Static source checks are not evidence of WCAG conformance or a live deployment.

**Level 2:** C06.9. **Level 3:** C08.5. **Next:** C06.2 — Public jurisdiction/topic browser, source-linked rule pages, coverage boundaries, effective dates and reviewed change history.
