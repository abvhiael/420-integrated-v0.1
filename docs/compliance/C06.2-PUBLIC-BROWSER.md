## Privacy, security and regressions

Catalogue fields and history fields are closed schemas. The public build contains no private author/reviewer workspace, identities, decision receipts, exact geography, orders or credential evidence. Safe slug IDs prevent path traversal; values are HTML escaped; source URLs require exact existing official hosts, HTTPS and no credentials/query/fragment. External links carry no-referrer protections. No scripts, forms, checkout or third-party runtime dependencies are introduced. The catalogue is outside the web serving root and private service records are never read by the builder.
