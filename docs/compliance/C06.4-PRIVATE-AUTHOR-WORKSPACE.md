## Gap analysis and implementation

Existing C03.2 supplies the structure-only policy schema, C02.3 integrity-checks archived source snapshots, C04 defines separate lifecycle/reviewer authority, and PostgreSQL already backs publication fences. No private author workspace existed. This step reuses these components and adds a private HTTP handler, protected embedded editor, citation adapter and private PostgreSQL version store. It changes no public catalogue, frozen address, evaluation/receipt authority or reviewer/publication transition.

## Session and HTTP boundary

C064AuthorAuthority is a required provider interface, not a local role issuer. VerifyAuthorSession must independently validate the opaque session cookie and return a current author grant, scope, audience, authenticated/MFA times and session-bound CSRF token. Every access verifies that assertion; writes and returned private data refresh it at point of use. Lifetime is bounded to fifteen minutes with a five-minute MFA window and the earlier grant/session expiry. Context deadlines stop expired operations. Identity-service revocation is required for logout. No identity/grant can be supplied through a draft request.

Use the configured exact HTTPS Origin and a __Host-420ComplianceAuthor cookie issued by the identity boundary with Secure, HttpOnly, SameSite=Strict and Path=/. Mutations require the exact Origin and X-CSRF-Token. Duplicate session cookies, duplicate JSON keys (including case aliases), unknown fields, invalid query keys, oversized bodies and excessive JSON depth fail. All private responses have no-store/private, no-referrer, nosniff and frame-denial headers; CSP permits only local scripts/styles/connections and blocks form submission and framing. No CORS grant is added.

Mount C064AuthorWorkspace directly on /private/author and /api/v1/author routes. Its private assets live under services/complianceauth/authorweb and are embedded in the authenticated handler, never served from compliance/web. Configure C064PostgreSQLDrafts with the existing protected primary DB connection, apply migrations/0002_author_drafts.sql, inject the scope-restricted archive adapter and genuine author identity authority. Missing any dependency disables the handler. These are executable integration seams; no deployed identity provider or private website is claimed.

## Persistence and privacy

Private heads are keyed by tenant/domain/jurisdiction/draft ID and retain the initial owner. Historical rows are keyed additionally by revision. A row lock serializes concurrent expected-revision saves across connections; head and immutable version insert commit together. Reads enforce scope/owner and validate the document commitment. Replica, cancelled-context, corrupt-document and database failures do not return a draft. There is no update/delete operation for historical versions in the author API.

The browser uses same-origin cookie authentication, an in-memory CSRF/session context, no-store requests and no redirect following. It has no local/session storage, token query parameter, private export, telemetry, approval or activation path. Source excerpts and diffs render as textContent. A conflict retains unsaved work, disables save and requires explicit reload instead of automatic retries. Expiry, revoked/forbidden/unavailable service responses, logout or an invalid private scope response clear inputs, cited text and differences. Generation checks prevent a late response from repopulating a cleared session.

## Qualification and limits

Eleven Node tests exercise structured draft construction, safe integers, anonymous bootstrap, the actual editor controller with save/load/preview/compare, conflict/reload, expiry/revocation/outage, logout, stale response cancellation, cross-scope response rejection and text-only rendering. This uses a minimal DOM harness, not a real-browser accessibility claim.

Go HTTP/security tests cover scoped editing and immutable comparisons, anonymous asset protection, TLS/Origin/CSRF, closed/duplicate/oversized input, role/session/MFA/expiry gates, cross-author/tenant reads, corrupt/quarantined sources, and revocation during source reads. A separate archive test verifies pinned-text integrity. Real PostgreSQL qualification is mandatory and cannot skip: two independent connections, twenty-four competing saves with exactly one winner, history persistence, owner/tenant isolation, corruption and outage. go vet and Go race run in app-specific CI. Existing Compliance Go/race/PostgreSQL and C06.1–C06.3 gates are retained. The artifact is labelled C06.4.
