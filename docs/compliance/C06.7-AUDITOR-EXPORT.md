# C06.7 — Auditor export and protected evidence inspection

**Canonical requirement:** Auditor export and evidence inspection with redaction, access logging and authorization.

## Implementation
- `C067AuditorService` requires an independently verified, unrevoked and case-bound auditor session. Domain/tenant/jurisdiction originate from the session, never the browser. Case authority is verified again after evidence reads and after durable logging.
- `C067EvidenceRepository` must implement scoped, integrity-verified lookups of previously archived evidence. The intentionally limited `C067EvidenceItem` has citation and digest metadata only; raw source bytes, personal identifiers, credentials, address details and original documents are excluded.
- `C067PostgreSQLAccessLog` writes purpose, actor, case, scope, evidence reference, action and time to the primary database. The export fails closed if the audit log cannot be committed. Production database privileges must forbid alteration/removal of audit rows.
- `C067AuditorHTTP` provides one TLS-only, same-origin, CSRF-protected private export route, requires independently verified HttpOnly cookie-backed session authority, and emits no-store headers.
- No publication authorization, reviewer approval, real legal certification, live domain or public route is created by this step.

## Targeted qualification
- `TestC067AuditorBoundedRedactedAccess`: authorized positive, missing/expired/revoked privilege, logging outage, duplicate evidence and quarantined source negative paths.
- `TestC067PostgreSQLDurableAuditAccess`: real PostgreSQL primary migration, independent-connection read-after-write, invalid actor, cancelled context and outage.
- C06.7 Go vet and targeted Go race suite added to app Level 1 workflow. Exact-SHA CI must pass before certification.

## Remaining production wiring and acceptance
Real identity-provider case grants, publisher retention/inspection conditions, production evidence repository with source integrity, durable backups and append-only database permissions need operator acceptance. HTTP returns metadata-only redacted exports; full original bytes remain controlled by the separate pre-existing C02.9 licensed source export boundary. Additional original-source export privileges may not be inferred from auditor access.
