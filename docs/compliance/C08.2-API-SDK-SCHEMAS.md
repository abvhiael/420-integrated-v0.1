# C08.2 — API and SDK contract (repository v1)

Authoritative implementation: `services/complianceauth/c05_1_api.go`. Documentation is descriptive; it does not install a new service or grant publication authority.

## Routes

| Method | Path | Input | Response | Security |
| --- | --- | --- | --- | --- |
| POST | `/api/v1/evaluate` | JSON: `tenant_id`, `operation_ref`, `stage`, `action`, `policy_digest`, `facts_digest` (all required strings) | JSON: `outcome` (`DENY`, `REVIEW_REQUIRED`, `ALLOW`), `reason`, optional `policy_digest` | Bearer token; independently verified tenant authority; optionally configured independent recovery gate |
| GET | `/api/v1/guidance?region=BC&limit=20&offset=0` | region required; limit 1–50, offset 0–100000 | `items[]` with `region`, `message`, optional `policy_digest`; optional `next_offset` | Non-authorizing guidance |
| GET | `/api/v1/policies/status?scope=BC&limit=20&offset=0` | scope required; same pagination | `items[]` with `scope`, `status`, optional `policy_digest`; optional `next_offset` | Non-authorizing status |

The evaluation request max JSON body is 16 KiB; unknown fields, trailing JSON, invalid digest and unsupported content type are rejected. Responses include `Cache-Control: no-store` and `X-Content-Type-Options: nosniff`. Failure responses use `{"error":"request_unavailable"}`; HTTP 400/401/403/405/406/415/503 depend on failure stage and are not permission grants. Caller MUST regard transport error, missing response, malformed response or non-ALLOW as **no authorization**.

The `ALLOW` policy digest MUST match the requested digest. An assessment is not a payment, custody, shipping, licensing or legal authorization: external mandatory preconditions and downstream stage-specific authorization still apply. The server's optional `RecoveryGate` is a code seam; production must configure authority scope/generation and fence *all* consumers before serving. Do not infer a safe default from an unconfigured gateway.

## Go client

`C051Client` exposes `Evaluate(ctx,request)`, `GetGuidance(ctx,region)` and `PolicyStatus(ctx,scope)`. Caller supplies an HTTPS base URL, secure `http.Client` and externally sourced bearer token; it stores no private signing key. Pin TLS trust and environment separately. The SDK must not turn `REVIEW_REQUIRED`, `DENY` or network failure into `ALLOW`.

## Model references

`C051DecisionRequest`, `C051Decision`, `C051Guidance`, `C051PolicyStatus`, `C051ListPage` and `C051API` are the source-of-truth model types. Independently authenticated reviewer, operator, auditor and consumer interfaces are distinct private flows; never copy an evaluation bearer token into them.
