# C08.2 — Operator runbook: deployment, incidents, recovery and monitoring

**Preflight:** confirm current exact implementation SHA, approved environment, separate authenticated workload identities, TLS trust chain, encrypted PostgreSQL, tenant boundaries, non-exportable managed signer, independent current publication/revocation/restore authority, approved jurisdiction policy digests, active legal reviewer mandate, and verified DOOBr/Travel consumer identities. Missing approvals mean deployment permission **DENIED**.

**Monitoring:** configure approved numeric thresholds for eight C07.7 signals: source freshness, reviewer backlog, decision latency, evaluator errors, coverage gaps, activation lag, revocation propagation and acknowledgements. Missing telemetry/threshold is UNKNOWN/CRITICAL, never a clean bill of health. Alert pipeline must durably acknowledge operator notification. Measure real RPO/RTO, on-call delivery and consumption SLA separately.

**Compromise or false approval:** invoke independently authenticated restrictive halt; revoke affected reviewer grants, device sessions and publication/signing keys with authoritative epoch. Fence current traffic/queue/worker consumers; preserve unrelated lawful refunds/refusals/returns. Log immutable incident and verify consumer ACK and replay denial. Neither an operator browser nor monitor can publish an ALLOW.

**Disaster recovery:** quiesce every gateway/consumer and worker; verify offsite backup/WAL integrity, schema and encryption; consult independently deployed monotonic revocation/privacy tombstone authority, restore to disposable isolated database first, replay deletions and advance generations/leases; retest authorization and consumer acknowledgements before a separately authenticated reopening. Never restore only SQL and reactivate stale/revoked law. The C07.6 real PITR and immutable external authority exercise remain C08.3/C09/C10 **OPEN**.

**Rollback:** block new regulated work, deploy only a separately approved non-stale signed version with monotonic epoch; rollbacks that lower sequence or revive deleted subject records are forbidden.

**Operator evidence:** timestamp, exact SHA, deploy manifest digest, owner, environment, authority generations, source/legal approval, reviewer roles, test run/job IDs, alert and recovery IDs, release authorization and final ACKs. No credentials or personal case data in public logs.
