# CMP-1.1.4.4 — canonical production wiring

**Status: implementation and automated wiring tests committed. Actual production deployment and publication NOT qualified.** This stage must not be represented as a deployed live Compute Market. PR #370 stays draft and unmerged.

## Intended canonical path

The only acceptable verification evidence address for this stage is a deployed `ComputeJobIntegerProfileVerification420` whose immutable `independencePolicy` points to the reviewed `ComputeVerifierIndependencePolicy420`, whose `jobs` binding points back to the *same* canonical `ComputeJobRegistry420`, and whose profile approval enables only the independently reproducible `INTEGER_SUM_OF_SQUARES/V1` profile. `ComputeJobRegistry420.verificationEvidence()` must point to that exact adapter; it cannot point to the signature-only primitive, a policy-only verifier, a permissive fixture, or another address. Signed request authority, actual-payer custody, accepted match and committed worker evidence must share the same exact job registry and upstream authorization and request references. The registry constructor freezes all six evidence addresses; there is no mutable verification-pointer repair path.

`contracts/src/compute/ComputeJobCanonicalWiring420.sol` provides an immutable **installation-specific audit record**, built with independently reviewed expected runtime code hashes and governance, identity-attestor, selector, policy-epoch and chain-ID values. Its constructor fails if the configured canonical installation does not meet the required bindings. Its public `assertWiring()` fails closed if the profile is disabled, roles or epoch drift, the chain changes or the recorded contract hashes/bindings do not match. A supplied hash equal to whatever code happens to be present is **not independent code review**. This checker does not enable, register, deploy, promote, or certify the installation by itself.

## Automated acceptance

The existing 1.1.4.1–1.1.4.3 suites must remain green. Obtain successful Solidity Contracts, 420 Integrated Qualification and 420Docs on the same exact PR head before closing the **automated wiring** gate.
