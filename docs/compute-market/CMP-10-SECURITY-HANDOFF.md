# CMP-10 — Security and adversarial qualification

**Operational disposition: NO-GO. Public incentivized testnet, independent security audits and real adversarial campaigns not yet performed.**

The canonical roadmap requires 16 distinct adversarial campaigns: external contract audit, worker sandbox audit, malicious workload execution, malicious worker/verifier/scheduler, collusion, Sybil workers, benchmark and hardware fraud, replay/stolen/duplicate results, reward farming, denial of service, dataset poisoning, supply-chain compromise, sandbox/container escape, key compromise, insolvency and stake/slash abuse.

This repository-only step adds `compute/ingestion/src/cmp10-security.mjs` as a structural fail-closed checklist with targeted tests. It requires all campaign names, retained evidence references, independent per-campaign reviewers, no high or critical vulnerabilities, independently corroborated external and sandbox audit conclusions, requalification after remediation, exact release SHA, prior actual CMP-0 operational success and real incentivized public testnet. **It is not an attack harness, an external audit, a penetration test, sandbox isolation verification, a security proof, or an independently authenticated receipt validator.** It must not be used to claim the actual campaign was run or that provider- or RPC-supplied evidence is authentic.

**Required live follow-up:** appoint external reviewers with scope and signed reports; deploy the exact release on an incentivized public testnet; execute actual malicious workloads/worker-verifier-scheduler attacks; run sandbox escape and permission-boundary penetration tests; exercise rate limits and denial of service; test collusion, Sybils, poisoned datasets, supply chain and key compromise; demonstrate CMP-5.6 replay prevention, CMP-6 Vault conservation, disputes and stake/slash restrictions; capture independent logs, chain finality and reorg evidence. Remediate findings and qualify the new implementation SHA. Do not proceed to CMP-11 while CMP-0 remains NO-GO or any live campaign remains absent/failed.

**Qualification:** Offline Level 1 verifies only the gate and retained science-ingestion regressions. Operational security Level 2 requires real testnet campaign on exact release and documented independent reviewers. Level 3 monolithic merge-candidate comprehensive suite remains later, with Solidity Foundry and Genesis address-ownership separated.
