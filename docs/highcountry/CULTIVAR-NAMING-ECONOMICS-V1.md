# High Country — Custom cultivar name fee and moderator/prize split V1

**Owner-approved initial economics:** custom names cost **5 $420**; the eligible final moderation review receives **50% (2.5 $420)**, independent of whether the name is approved or rejected. The other **50% (2.5 $420)** belongs to a separately controlled **High Country competition/prize vault**, not to the developer's discretionary personal balance. Free deterministic parent-combination naming remains available to all eligible players and does not generate a moderator payout.

## Dynamic affordability without oracle manipulation
- Current base quote: 5 $420. Higher market value should permit governance to **reduce the denomination** in subsequent versions.
- Version V1 permits only **authorized downward fee updates**, not continuous spot-price conversion; do not change an already accepted quote.
- Value observations are advisory until a trustworthy source, TWAP length, price currency, target cost, minimum fee, rate limits, stale-data bounds and oracle failure behaviour are separately approved and qualified. No oracle feed or market price is fabricated.
- Fee snapshots identify fee version, token base-unit amount, quote expiration and request ID before taking payment.
- Native token decimals must be read from the actual authorized asset; 2.5 tokens must be representable in its precision. Split integer base units: reviewer=floor(amount/2), competition vault=amount-reviewer.
- Amounts are paid for one **eligible completed moderation review**, not for deletion or for a rejection outcome. Prevent self-review, coordinated spam, repeat claims, duplicate cases and financial gaming.

## Escrow and conservation
- Collect once per accepted paid-name proposal into audited escrow; assign 50% reviewer payable and 50% competition prize liability.
- Only release the reviewer share after independent finalization of a legitimate review; restrict funding and disbursement roles and keep immutable correlation to cultivar ID/name revision.
- Prize share is transferred to a scoped competition vault with separate prize disbursement permissions and auditable rules, not automatically spent as prizes.
- Explicit cancellation, failed submission, repeated renames, appeal and refund accounting must be approved before deploying fee collection.
- Existing moderation registry and admin UI **do not currently collect or distribute $420**. Build the token escrow, vault, invoice and atomic/reconciled claims flow as a separate audited integration.

## Example accounting
| Item | Initial V1 tokens |
|---|---:|
| Custom name charge | 5 $420 |
| Reviewer share (50%) | 2.5 $420 |
| High Country competition vault (50%) | 2.5 $420 |
| Free autogenerated name | 0 $420 |

Review compensation is the same for approval and rejection and must never incentivize more rejected names.
