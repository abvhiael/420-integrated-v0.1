# High Country — Paid naming service implementation gates

Current scope: draft on PR #677; do **not** deploy unreviewed payment contracts or name backend to mainnet.

- `CultivarNamingEscrow`: native $420 via `msg.value` only on chain where $420 is native coin, **not** ERC20. Paused by default; attested quotes by a designated publisher; unique deposit; adjudicator finalizes exactly once, with 50/50 pull-payment ledger and separate refund path; native outgoing transfers use a reentrancy guard. Publisher and adjudicator must be independent trusted roles. Owner pause is not an arbitrary withdrawal.
- **Oracle limitation:** JS pricing service implements deterministic 7-day TWAP calculation but does not fetch, authenticate or verify independent external feeds. Quote publisher MUST validate feed provenance, coverage, sample count, outliers, per-week window, anti-manipulation and chain/token decimals before publishing. A compromised publisher can still publish false quotes. No production pricing oracle is wired.
- **Appointment limitation:** `ModeratorAppointments` requires injected durable store, server-side MFA verification, capability grant/revoke adapter and audit sink. It is a service module, not an exposed authenticated API or deployed backend. The existing JSX panel likewise has no deployed route. Do not expose untrusted IDs or plaintext evidence.
- **Moderation limitation:** normalized blocklist screening and async contextual moderation hooks require separately approved dictionaries, human-review provider, durable transactional store and real access-controlled routes. These must fail closed if unavailable. Registry `usable(id)` is not wired into inventory, breeding, listings, grants, search and trade authorization. A forbidden cultivar may still be usable by other services until these checks are integrated.
- **Escrow limitation:** adjudicator is trusted to prove a paid, finalized unique independent review and respect no self-review. The contract enforces no-self-payment and replay, but does not verify on-chain moderation registry finalization. Build an authenticated decision-verification adapter or bind directly before mainnet.
- External UI and economy: verify wallet optional baseline, transparent fee/refund disclosure, account sanctions audit and appeals before release.
