# Port Alder map catalogue and milestone visual stage

This scope connects Emerald Coast regional navigation to Port Alder; exposes 13 artwork-pixel polygons corresponding to immutable HC-EC-S01 district IDs; and selects Genesis or developed-50 overview art. Uploaded file paths are used unchanged, including the double .png.png extension on two original assets. No binary rewriting or title issuance.

The polygons are **provisional image hitboxes** rather than approved cadastral geometry. They are kept separate from the HC-WORLD-06 local tile navigation polygons. Their illustration registration will require owner visual sign-off; individual scenes render genuine owned improvements separately.

**IMPORTANT — staged backend integration required:** The browser requests an authenticated `/api/highcountry/world/port-alder/purchase-milestone` snapshot, but this implementation does **not** install an issuance/settlement-backed service endpoint. Without that server-side source, or when offline, unverified, errored or malformed, the browser always renders the Genesis image. Client-supplied purchased counts, guest saves and any speculative development metrics never select the developed artwork. A secure future endpoint must count distinct qualified, finalized 420 title IDs held by non-reserve owners, using the canonical eligible Port Alder title inventory as denominator, provide revision/finality provenance, and enforce canonical evidence freshness. Never route user-submitted or guessed counts into this endpoint.

The existing illustrative Emerald Coast image may contain noncanonical names; keep it labelled illustrative until separately art-corrected. County image currently uses an accessible Port Alder link rather than inventing a georeferenced pin hitbox. Heritage markers must never be published before individual discovery and fragment claim.

The maps share routing identifiers; the two art stages are concept representations, not per-property snapshots.
