# A01 · Original Sixteen art-direction standard

**Illustrated heritage letterpress**: ornamental Victorian seed-catalogue borders, coarse engraved silhouettes, aged cream paper, restrained metallic gold, subtle imperfect registration, readable high-contrast typography. No photorealistic mockup is the source of truth. The 13 vector SVGs are **editable master assets** and must be visually reviewed before final approval.

## Palette / region identity
- Emerald Coast: evergreen `#163b32`, sea-glass `#427e72`, mist `#c2cfbf`, aged gold `#dbc28a`.
- Golden Prairie: midnight navy `#27364b`, wheat `#ad7e37`, straw `#e0c18a`, pale brass `#e9d0a2`.
- Red Mesa: crimson oxide `#512c30`, mesa rust `#b15c40`, sandstone `#dfa979`, antique brass `#ebc68e`.
- Neutral field: paper `#f3ead5`, ink `#27332b`.

## Type and exports
- Display serif: Georgia-compatible; production font choice must be checked for license/availability. Body: readable serif, menu: clear sans serif; avoid embedding redistributable font binaries.
- Native masters: scalable SVG with labelled semantic groups and stable viewBox; no linked images, external scripts or web font dependencies.
- Raster exports: 2048px tall seed packets; archive/card art 1600px; UI 1x/2x WebP + PNG fallback; badges/stamps transparent PNG with padding. sRGB and documented SHA-256; allow higher print DPI if needed.
- No THC/potency, effects, terpene profiles, flowering times or unproven genetically fixed morphology on package art.
- Every downstream founder asset references HC-FNN, provenance metadata and the approved region palette.

**A01 qualification:** asset count 13; all valid XML/SVG; unique paths; no active scripts/external references; text render and contrast/a11y reviews; screenshots from actual client still outstanding. No Level 1 certificate claimed by creation of this document.
