## Canonical exit criteria and implementation

- **Awaiting signature / submitted:** `apps/highcountry-web/src/transaction.js` has a stateful explicit begin/sign/submission boundary. A *reviewed* operator-supplied `highCountryReviewedTransaction.submit` adapter is the only UI entry to requesting a signature, never unchecked browser target/data/value fields. Rejection leaves the operation awaiting explicit reconsideration. An ambiguous request marks unknown/unavailable and cannot silently resubmit.
- **Pending:** independently checked RPC chain plus receipt absence or finalized-head lag results in pending, not a fictional success. Missing independent witness also remains pending even if the main RPC claims a finalized block.
- **Finalized:** correct chain, transaction hash, canonical block hash, finalized height and an affirmative separately configured independent R05.7 witness are required. Even independently finalized **inclusion is not proof of market escrow settlement, reward issuance or BUDS payout**.
- **Reverted / reorged:** explicit receipt status 0, mismatched canonical block hash, replaced receipt anchor or disappeared prior receipt are handled without crediting an economy result. Recheck is manual; no operator-only settlement actions are exposed to the browser.
- **Duplicate-click / replay:** operation IDs unique, once-submitted operation cannot be sent again; in-flight check serialized; manual observe rejects conflicting transaction hash.
- **RPC and indexer unavailable / empty / loading:** `apps/highcountry-web/src/account.js` shows distinct failure, empty, loading, pending, denied and reorged messages. Authenticated R05 `/events` data are labelled projections, not proof of canonical finality.
- **Recovery:** user can explicitly observe a known hash after uncertain submission and verify canonical status. Browser does not automatically resend, auto-refund, or claim settlement on timeout. Durable browser-restart transaction history and operator recovery signoff remain separate R06.8/R07 deployed evidence; production adapter acceptance is OPEN.
