# High Country R06.6 external/testnet acceptance gates (OPEN)
- HC-R06.6-T01: Independently approve the **exact zero-value reviewed routine selectors**, allowlisted targets, game and chain addresses; verify execution cannot transfer value, expand permissions, mutate economic balances, or use unreviewed calldata.
- HC-R06.6-T02: Configure real game-scoped identity issuer and revocation/expiry authority, independently provision the PostgreSQL 007 durable operation journal under a restricted runtime role, and prove principal/session/epoch isolation across restarts and concurrently deployed services.
- HC-R06.6-T03: Activate independently verified wallet/passkey escalation for sensitive calls, bound to the exact principal, operation, action, nonce and expiry; confirm real hardware/provider consent and challenge replay protections.
- HC-R06.6-T04: Deploy the secure HTTPS `/v1/routine/execute` gateway behind the approved identity and action policy, validate permitted Origin/CORS, and obtain operator/security approval on browser, mobile and network conditions.
These are external acceptance requirements. No default action policy, session minting, global delegated signing permission or production routine behavior is enabled by the repository implementation.
