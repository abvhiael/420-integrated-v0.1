# LIFTd L02.2 — rider account and preferences

Canonical deliverable: account/session management, accessibility requirements, communication preferences, privacy controls.

## Boundaries
L01 Identity/session owner is authoritative. L02.2 introduces an independently authenticated account-scoped preference service and a fail-closed interface contract, **not a new identity issuer**. Caller-provided `authorize(token,{action:'account.preferences',resource:'account:<id>'})` must verify the L01 active identity, session, revocation/recovery state and account binding. This permission must be added to the canonical L01 authorization registry and independently tested before deployed requests are permitted; the service has no permissive fallback. `store` must implement durable transactional read/compareAndSwap/delete; tests use an isolated in-memory fixture only. No claim of deployed persistence is made.

## Controls
Accessibility: large text, reduced motion, screen-reader hints. Communications: explicit contact method (none/email/SMS), opt-in trip notices, marketing opt-in disabled by default. Privacy: location-history consent disabled by default. Unknown fields and unsafe types are rejected; notification opt-in without contact method is rejected. Reads/updates/deletes all require the same scoped active credential. Revision-based compare-and-swap prevents blind concurrent overwrites. Deletion is explicit. Sensitive values are not logged, placed on-chain or exported to client-side storage.

## Qualification
The dedicated L02.2 Node 22 Level 1 workflow tests defaults, opt-ins, invalid types, malicious object accessors, cross-account and absent credentials, revision conflicts, deletion, and retained L02.1 route policy. Live Identity binding, durable PostgreSQL transaction integration, account self-service browser UX, independent accessibility/device acceptance and actual communications delivery remain outstanding and must **not** be marked operationally complete solely from fixture tests. Full Solidity/Genesis/Integrated/Docs reruns belong to Phase L02 Level 3, not this ordinary scoped step.
