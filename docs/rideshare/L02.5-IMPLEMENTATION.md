# LIFTd L02.5 — rider trip experience

Canonical scope: assignment, driver and vehicle identification, arrival, in-progress and completed state, scoped contact, cancellation and incident reporting; estimates must never masquerade as confirmed events.

The rider screen is guarded by L02's authenticated rider route and uses the existing canonical L01 trip reader (`GET /v1/rideshare/trips/:id`), revisioned pre-trip cancellation (`POST /v1/rideshare/trips/:id/transitions`), and scoped safety incident reporting (`POST /v1/rideshare/trips/:id/safety/report`). L01 verifies the active signed session, rider ownership, authorization and durable transitions. New client code does not authorize or directly mutate trip state.

`trip-experience-policy.mjs` validates source, rider binding, state/revision and driver/vehicle pair; `trip-experience-controller.mjs` re-reads authoritative state after commands, rejects duplicate concurrent commands, preserves retry idempotency keys after uncertain results and disallows cancellation in-progress or after terminality. `trip-experience-view.mjs` labels **confirmed** assignment, arrival, in-progress, completion and cancellation; it does not infer provider ETA or GPS and never treats command acknowledgment as a state transition. Driver and vehicle IDs are shown only when assigned. Contact is expressly scoped and disabled until an approved authenticated messaging adapter exists; no uncontrolled phone number or direct link is exposed. This explicit fail-closed contact gate is not acceptance of a live contact workflow.

Dedicated L02.5 fast qualification covers malformed/cross-user/stale snapshots, assigned states, cancellation replay/terminal restrictions, incident categories, no simulated contact and retained L02 web tests. Production contact adapter, real device/browser accessibility and notification/ETA consumers require L02 integration and independent external acceptance. No production rides, payments or dispatch are implied.

Level 1 only at this step; Level 2 at the relevant L02 integration milestone, and one Level 3 after full phase reconciliation with then-current main.
