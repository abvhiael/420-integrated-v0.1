## Canonical requirements and completed repository work
- **Private rider–driver conversation:** `trip.message.read` and `trip.message.send` are separate signed-session-scoped grant actions in L01 auth, checked against actual active trip ownership and assignment. API only accepts authenticated participant actions for ASSIGNED/ARRIVED/IN_PROGRESS. Neither operator nor cross-trip caller inherits conversation permission.
- **Membership expiry/revocation:** short-lived Messenger-owner grant must match trip ID, revision, actor, recipient and expiry, bounded by verified session. Fresh L01 session and trip reads block reassignment, cancellation, completion, inactive/expired session, invalid identity or stale revision. Durable transport acceptance must independently revalidate the membership and revoke a former participant when the assignment changes or trip terminates.
- **Trip updates:** `notifyTripEvent` validates a real trip revision and authenticated participant, then provides the canonical 420Notifications owner only a whitelisted trip-status event with stable event command ID. The externally owned delivery source/worker remains disabled until independently deployed, credentialed and accepted.
- **Delivery preferences:** notifications only route when authoritative `preferencesFor` reports explicit trip-notification opt-in and permitted email/SMS contact method; absence of consent defaults to no delivery. Client controls never bypass the server preference owner.
- **Redaction/privacy:** notification event contains only trip ID, state, revision and a typed event marker; no plaintext message, coordinates, detailed route, personal identifiers, provider credentials, payment data or contact token. Messenger client text is presented via DOM `textContent` and protected no-store authenticated HTTP, never interpreted as HTML.
- **Client integration:** fail-closed messaging UI integrated into the L02.5 rider trip and L02.8 driver trip panels and independent session adapter. The UI never treats acceptance as delivery finality.
- **Changed scope:** `rideshare/src/{auth,http,trip-communications}.mjs`, `rideshare/web/{trip-messaging,trip-experience-view,driver-trip-view,app}.mjs`, `rideshare/test/trip-communications.test.mjs`, `.github/workflows/liftd-l02-9-level1.yml`, `docs/rideshare/L02.9-IMPLEMENTATION.md`.
