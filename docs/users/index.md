# Use 420 Integrated

Task-oriented documentation for people using the 420 Integrated ecosystem.

The first complete user journey is 420 Wallet onboarding: choosing a qualified client, connecting or discovering an account, protecting it, sending and receiving native `$420`, connecting dApps, reviewing signatures, managing permissions/sessions, recovering after device or owner loss, and troubleshooting common problems.

## 420 Wallet

- [Wallet onboarding](wallet/index.md)
- [Set up, import, and protect an account](wallet/setup-import-and-protection.md)
- [Send and receive `$420`](wallet/send-receive-and-activity.md)
- [Connect applications safely](wallet/dapp-connections.md)
- [Review and sign safely](wallet/signing-and-transaction-review.md)
- [Manage permissions and sessions](wallet/permissions-and-sessions.md)
- [Recovery, lost devices, and account safety](wallet/recovery-and-device-safety.md)
- [Troubleshoot 420 Wallet](wallet/troubleshooting.md)

Later user documentation will add task guides for identity and names, bridging, staking, governance, and the remaining genesis applications.

The goal is practical: users should be able to complete common tasks without needing to understand protocol internals.
