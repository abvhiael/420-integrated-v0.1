# W15.6-M9 — Hardware wallet integration qualification

**Priority:** High. **Hardware testing required.** This branch is a partial implementation, **not milestone completion**.

## Implemented in this branch

- Ledger Ethereum application public-address retrieval using user-initiated Chromium WebHID selection, bounded BIP-44 `m/44'/60'/account'/0/index` paths, Ledger transport framing and sequence/length validation, 25-second timeout and explicit device close.
- Public key/address cryptographic equality check; never trust the address string from a USB device without reconstructing it from the returned public key.
- Explicit wallet manager flow for up to five device-confirmed Ledger addresses per selection, public account/derivation path storage and display, with no mnemonic, private key or signed payload persisted.
- The current extension's hardware/watch-only signing prohibition is retained. Unverified accounts cannot silently sign or broadcast; a device address alone is not authority.
- Trezor is listed but not connected, with explicit no-device-paired behavior. No hosted, remotely loaded SDK or unaudited vendor code added.
- Protocol-only adversarial tests cover path bounds, HID frame channel/sequence/truncation and public key/address mismatch.
