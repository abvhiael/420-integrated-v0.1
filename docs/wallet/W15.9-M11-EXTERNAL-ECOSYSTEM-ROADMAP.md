# W15.9-M11 — Optional external integrations and on-device qualification

**Origin:** W15.6-M11 Phase 11. **Status:** only externally dependent live qualifications deferred. Local privacy, on-chain portfolio analytics, encrypted metadata backup, service discovery, full-page UI, local notifications and WalletKit protocols must pass software CI.

- **W15.9-M11-01 — WalletConnect v2 relay / mobile device:** Approved WalletConnect project ID and wallet application HTTPS identity, real peer pairing and namespace approval, accounts/chain/method checks, rejected/expired proposals, actual EOA/hardware/SmartAccount signing, mobile/desktop device/browser tests, relay and MV3 service-worker restart/connection recovery. Offline mocks do not prove 24/7 relay connectivity.
- **W15.9-M11-02 — Encrypted cloud backup/sync:** Local AES-256-GCM encrypted metadata import/export is implemented. No remote sync provider is approved. Remote sync of vaults, contacts, recovery material or grants remains disabled; qualification requires independent security/privacy review, end-to-end encrypted transport, conflict resolution, opt-in, revocation, deletion and device recovery.
- **W15.9-M11-03 — Push notifications:** Existing opt-in local browser alerts do not imply qualified mobile push. External notification providers require consent, redacted data, receipt/reorg evidence, delivery worker and suppression on revocation.
- **W15.9-M11-04 — Service discovery:** Independently verify exact deployed 420Swap, 420Stake, 420Names, 420Identity, 420Bridge, 420Exchange and other genesis applications and registered HTTPS origins. A displayed app link never authorizes its account access.
- **W15.9-M11-05 — Mobile / browser acceptance:** Genuine Android/iOS device and desktop extension pairing via WalletConnect, QR/deep links, account and chain changes, pairing declines, app lifecycle, privacy masking, accessibility and full-page browser acceptance.
- **W15.9-M11-06 — Independent W15.10 review:** WalletKit dependency/relay trust, remote proposal origin spoofing, session persistence, privacy policy, local backup encryption and recovery, exact-SHA audit and production release gating.

Unverified providers, relays and deployed service identities fail closed. Existing Phase 9 hardware and Phase 10 financial live/testnet gates remain independent.
