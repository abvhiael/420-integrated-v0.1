
# 420 Integrated Testnet — User Quick Start

## Add the network

Use the published wallet configuration:
- Network: 420 Integrated Testnet
- Chain ID: 420
- Currency: 420
- RPC: use one of the officially published HTTPS endpoints
- Explorer: use the officially published explorer URL

Never add a network from an unofficial URL without checking the published genesis/release hashes.

## Get test 420

Use the official faucet. Testnet 420:
- has no monetary value;
- is for testing only;
- may be reset or retired;
- is not redeemable for mainnet 420.

## Verify the network

Before interacting:
1. confirm chain ID;
2. confirm RPC hostname;
3. compare published genesis hashes;
4. compare the release checksum if running a node;
5. confirm the explorer shows the same finalized block as your node/RPC.

## Send a transaction

Any standard EVM wallet may submit ordinary transactions through the public RPC endpoint.
Gas is paid in testnet 420.

## Report a problem

Use the official status/incident channel and include:
- transaction hash;
- block number/slot if known;
- RPC endpoint used;
- UTC timestamp;
- client/wallet version;
- error message.
