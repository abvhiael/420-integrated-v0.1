Security Centre

Website Disconnect removes only local browser account access. ERC-20 approvals, SmartAccount capability grants, session keys and passkeys are independent on-chain authorities. They require their own verified transaction to revoke.

Inspecting security authorities…

Connected websites & granted accounts

Security alerts

Signature history

Token allowances

Inspect a specific ERC-20 contract and spender. Values are read from that contract on the selected chain; this does not discover every spender. Revocation calls approve(spender,0) and costs network fees.

Recently observed approvals

Recent event discovery is bounded and never a complete allowance inventory.

SmartAccount420 authority

Capability grants

Inspect an exact canonical grant ID. Revoke via the SmartAccount420 owner and canonical CapabilityRegistry420, never by disconnecting a website.

Session keys

A session key is active only in its authorization epoch. Expiry can also be imposed by its canonical session grants; merely hiding a key locally does not revoke it.

Passkeys

Only locally enrolled credential references are shown. A passkey revocation requires the current canonical SmartAccount420 owner's on-chain approval.

Recovery authority

Changing recovery authority or resolving a pending recovery is a distinct SmartAccount owner/recovery authority action, not a website permission change.
