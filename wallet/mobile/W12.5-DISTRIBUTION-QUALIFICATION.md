# 420 Wallet — W12.5 Distribution Qualification

W12.5 validates the assembled Android/iOS release contracts as one distribution candidate without weakening the physical-device release gate.

## Repository-side qualification

Run:

```bash
npm run distribution:qualify
```

The qualification checks:

- canonical release manifest and release-bundle identity;
- SHA-256 artifact provenance policy;
- Android Play packaging contract;
- iOS App Store/TestFlight packaging contract;
- external-only signing policy;
- absence of committed signing material and wallet secrets in release/distribution configuration;
- preservation of `wallet-core-canonical-v1` authority policy;
- preservation of `npm run device:closeout` as the production release gate.

## Production readiness

Repository qualification may pass while production release readiness remains `BLOCKED_EXTERNAL_DEVICE`.

Production/TestFlight/Play readiness becomes eligible only when `device-qualification-results.json` contains genuine physical-device evidence for Android and iOS and:

```bash
npm run device:closeout
```

passes.

Simulator/emulator results do not satisfy that gate. Signing credentials, certificates, provisioning profiles, keystores, App Store Connect keys and Play upload credentials remain external to the repository.
