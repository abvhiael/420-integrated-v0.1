# W13.5 — Graphics and visual assets

W13.5 adopts the supplied 420 Integrated blue/green interlocked logo as the canonical project and wallet brand source.

## Canonical source
- `design/app-icon-master.svg` — icon-only blue/green interlocked mark on white.
- `design/420-integrated-wordmark.svg` — full mark with `420 INTEGRATED` wordmark.
- Canonical colors: blue `#273B9C`, green `#45B84A`, wordmark `#20397E`, white `#FFFFFF`.

## Platform binding
- Android launcher icon is bound through `@mipmap/ic_launcher` with adaptive and legacy vector resources derived from the canonical mark.
- iOS output sizes and filenames are defined in `ios/AppIcon420.asset-manifest.json`; generated PNGs must come only from the canonical master source.
- Launch/splash presentation uses the canonical mark/wordmark contract in `design/brand-assets.json`.

## Supporting illustrations
- `design/illustration-empty-wallet.svg`
- `design/illustration-security.svg`

These are presentation-only and contain no real addresses, keys, seed phrases, transaction hashes, signatures, or personal data.

## Qualification
`npm run brand:assets:check` verifies the canonical files, brand colors, Android launcher binding, iOS marketing-icon contract, presentation-only authority declaration, and secret-like-data guards.

W13.5 graphics never become account, signing, capability, recovery, RPC, or UserOperation authority.
